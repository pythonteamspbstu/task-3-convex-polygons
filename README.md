Задача 3: Выпуклые многоугольники

Реализация на языке Python для работы с выпуклыми многоугольниками на двумерной плоскости. Этот проект предоставляет комплексный класс для создания и манипулирования выпуклыми многоугольниками с помощью различных геометрических операций.

Класс CPolygon поддерживает вычисление периметра и площади, проверку выпуклости, тестирование содержания точек, пересечение многоугольников и триангуляцию. Программа включает интерактивную систему меню для ввода многоугольников и выполнения операций с ними.

Ключевые функции включают обнаружение пересечения многоугольников, проверку содержания как точек, так и других многоугольников, а также автоматическую проверку выпуклости во время инициализации многоугольников. Все геометрические вычисления используют методы перекрестного произведения для получения точных результатов.
